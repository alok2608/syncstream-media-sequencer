# Bundled demo media

These clips are used only for the seeded demo playlists. Replace or remove them
freely; the application itself has no dependency on them.

Both clips are approximately 10 seconds long, which makes them useful for
demonstrating that the **configured** duration - not the file's own length -
drives playlist progression: a 10s clip in a 30s slot simply loops three times.
